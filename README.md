## ¿Qué quieres hacer?

| | Opción | Cuándo usarla |
|:--:|:--|:--|
| 🐛 | **[Reportar un bug](https://github.com/salesjorgeapp/SalesJorgeApp-Issues/issues/new?template=bug_report.md)** | Algo falla, muestra datos incorrectos o no hace lo que debería. |
| 💡 | **[Proponer una idea](https://github.com/salesjorgeapp/SalesJorgeApp-Issues/issues/new?template=feature_request.md)** | Una herramienta nueva o una mejora que te ahorraría tiempo. |
| 💬 | **[Preguntar o debatir](https://github.com/salesjorgeapp/SalesJorgeApp-Issues/discussions)** | Dudas, cómo se hace algo o conversación con otros usuarios. |
| 🔎 | **[Ver lo que ya está abierto](https://github.com/salesjorgeapp/SalesJorgeApp-Issues/issues)** | Puede que alguien ya lo haya reportado: añade tu 👍. |

> [!TIP]
> **Atajo desde la extensión:** botón de feedback en la barra lateral del popup, o **Ajustes → Feedback**.
> El issue se abre ya relleno con la versión, el navegador y la herramienta.

## Un buen reporte

1. **Un problema por issue**, con un título concreto: *«[Data Import] Se para al 50 % con CSV grandes»*.
2. **Pasos para reproducirlo**, lo que esperabas y lo que pasó.
3. **Una captura** si ayuda a entenderlo.

> [!WARNING]
> Este repositorio es **público**. Nunca pegues contraseñas, tokens, IDs de sesión ni datos de clientes — difumina las capturas antes de subirlas.
